# Bitcoin Address Generation - Important Note

## Issue Found

The test showed that addresses like `tb1x57cnl9es4mjsvpsyj` are **not real Bitcoin addresses**. They were placeholders generated by the old code.

## Solution Implemented

I've added real Bitcoin address generation using `bitcoinjs-lib` and HD wallet (BIP32/BIP44).

### What Changed:

1. **New File**: `lib/bitcoin-wallet.ts`
   - Real Bitcoin address generation
   - HD wallet support (BIP32/BIP44)
   - Proper testnet/mainnet addresses

2. **Updated**: `lib/bitcoin-address.ts`
   - Now uses real address generation
   - Stores derivation paths for tracking

3. **Migration**: `007_add_derivation_path.sqlite.sql`
   - Adds `derivation_path` column to track HD wallet paths

## Important Security Note

⚠️ **The master seed is currently generated randomly each time the server starts.**

**For production, you MUST:**
1. Set `BITCOIN_MASTER_SEED` environment variable with a secure, persistent seed
2. Store the seed in a secure key management system (AWS KMS, HashiCorp Vault, etc.)
3. **NEVER commit the seed to version control**
4. Use a hardware security module (HSM) for production
